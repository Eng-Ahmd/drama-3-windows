Percentage of total VRAM to keep free (1–25%, default 3%). This is a memory reserve, not GPU compute utilization. Whole-bank placement can leave more free. The monitor stops the model if memory falls below the reserve.

Manual range: 0–40 tail layers. Each whole bank holds 256 experts, with 8 selected per token. Zero keeps expert banks on CPU; the backbone still requires CUDA. More layers require more VRAM.

    Generation settings

    01

    Generation

    Single pass submits the whole script in one model request and disables text splitting. Segmented mode divides the text into bounded passages, conditioning later passages on audio history. Long-form fidelity remains experimental.

    Total acoustic-frame allowance across the entire script, shared by every segment. This is a cap, not a duration target or completion percentage. Single pass supports up to 8192 frames; segmented mode supports up to 65,536 total frames. Each segment must fit the 10,240-row context, including reference and audio history. Larger totals allow longer work but do not guarantee accurate speech.

    Up to approximately 4m 45s of audio.

    The 32–2000-character passage cap is software validation, not the model’s token or context limit. Smart splitting prefers paragraphs, then sentence boundaries; oversized text falls back to word boundaries. Speaker cues are preserved. Smaller passages can change pacing and continuity. Single pass sends zero and disables splitting. The frame budget is total across every passage.

    Off by default. If generation reaches the frame limit before its end token, enabling this saves a clearly marked incomplete recording. With this off, the runtime rejects a partial result rather than publishing it.

    02

    Sampling

    Random seed (0–4,294,967,295). The same prompt, reference, settings and runtime can help reproduce a run. A seed does not select or fix a voice; hardware and runtime changes can affect output.

    Temperature rescales sampling logits. Default 0.7 sharpens the distribution; 1 leaves it unscaled and usually allows more variation. Lower positive values favor likely choices; higher values increase variation and can weaken pronunciation or coherence. Zero is invalid, not a greedy mode.

    Nucleus sampling keeps candidates covering this probability mass. 0.7 means roughly 70%; 1 disables nucleus truncation. Higher values allow more diversity. Must be greater than 0 and at most 1.

    Limits sampling to the K highest-probability candidates. Default 30. One is mostly deterministic, but the runtime’s built-in repetition-aware sampling can still affect selection. Must be a positive integer.

    03

    Export

    WAV is lossless PCM 16-bit at 44.1 kHz. MP3 is a lossy export and needs FFmpeg with libmp3lame installed. The original WAV remains available.

    MP3 bitrate: 128–320 kilobits per second. Higher values generally preserve more detail and create larger files. This is not the audio sample rate. Default 192 kbps.
